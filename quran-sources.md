# Sources de contenu Quran

Salawat charge à la demande le catalogue et le texte arabe depuis Al Quran Cloud : https://api.alquran.cloud/v1/surah et https://api.alquran.cloud/v1/surah/{number}/quran-uthmani. La documentation générale est disponible sur https://alquran.cloud/api.

La traduction française affichée dans l’application utilise QuranEnc, clé `french_rashid`, publiée comme « La traduction en français - Rachid Maach », version 1.0.3 : https://quranenc.com/api/v1/translations/list/fr?localization=fr. Les versets sont récupérés par sourate via https://quranenc.com/api/v1/translation/sura/french_rashid/{number}.

QuranEnc indique que ses traductions peuvent être téléchargées et republiées sous conditions : ne pas modifier, ajouter ou supprimer le contenu ; mentionner clairement QuranEnc et la source ; indiquer la version ; conserver les informations de transcription ; signaler les remarques ; mettre à jour selon les nouvelles versions ; ne pas afficher de publicités inappropriées. La traduction est donc attribuée dans l’écran Quran et affichée sans modification. Référence : https://quranenc.com/en/home/api/.

Quran.com décrit également les fonctions de lecture, traductions, audio, recherche, favoris, notes et suivi de progression qui pourront être ajoutées dans une étape ultérieure : https://quran.com/about-us.
